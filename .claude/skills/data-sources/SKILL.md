# 取料源清单

## 用法

1. 动手取料前先查库：读 wiki/index.md 找相关页，用 Glob 搜 raw/ 文件名（含 raw/reports/数据快照/），库里已有能用的直接复用并报告出处，不重复下载；确有缺口才按下表外出取数
2. 取料先按需求类型查下表对应分类，用 Playwright MCP 打开抓取；下载的 PDF 等文件一律存 raw/inbox/ 走收件台，不直接进正式目录
3. 宏观数字（GDP/CPI/PMI/社融/利率等结构化序列）优先走 macro-data 技能的 API 模板（AKShare、统计局新 API），本表的统计局/央行页面用于发布公告与新闻稿
4. 慧博只用免登录榜单（新财富排名、热度排行），不登录、不下载正文（2026-10-29 实测登录后详情页仍无 PDF 直链，登录功能已移除）；研报下载走东财研报中心免登录入口。发现报告的深度报告要积分，遇付费内容如实报告，不硬闯。新财富前 3 券商在东财取不到且顺延也补不齐时，提醒用户可自行在慧博终端下载缺的券商研报 PDF，从网页上传或放 raw/inbox 摄入
5. 政府站点限速温柔抓，正常逐份下载，禁止批量高频

## 源清单（2026-10-24 实测全部可访问）

### 研报下载

- 慧博投研 https://www.hibor.com.cn — 研报库存量最大，覆盖宏观/行业/公司 — **只做榜单源，不做下载源**（2026-10-29 定：登录后详情页也无 PDF 直链，只有终端推广层，本项目已移除慧博登录）。选样板要的新财富排名在这里：
  - 新财富最佳分析师历年排名 `https://www.hibor.com.cn/author.html?year=<年份>&bigtype=2`（bigtype=2 为新财富，1/3 是其他奖项），按行业组列上榜团队与名次（实测汽车组前 5 名，机构与分析师姓名），覆盖 2008-2025。2025 年汽车和汽车零部件第 1 名为东吴证券（黄细里、刘力宇、孟璐），2026-10-29 实测
  - 热度排行 `https://www.hibor.com.cn/hytop.html` 热点研报页，表头含热度数值列；另有 `rightmore_0.html` 今日热门、`rightmore_6_*.html` 本月热门、`rightmore_2_*.html` 热门行业。单篇详情页不显示热度，热度只在榜单页取
- 东方财富研报中心 https://data.eastmoney.com/report/ — 各券商研报聚合，可按行业/券商/日期筛 — 免登录，**研报下载首选源**。注意覆盖不齐：有的券商（如长江证券、国联民生）在研报列表里一篇都没有，取不到时按榜单名次顺延换下家。列表接口 `reportapi.eastmoney.com/report/list` 的 count 字段是阅读计数（页面不展示，仅接口可得），行业筛选用 industryCode 数字码（汽车类只有 481 汽车零部件，整车研报也归在这类）
- 发现报告 https://www.fxbaogao.com — 研报搜索引擎，行业深度报告多 — 游客可搜可看，深度报告要积分

- 披露易 https://www.hkexnews.hk — 港股公告财报 — 免登录

### 宏观数据与发布

- 国家统计局 https://www.stats.gov.cn — GDP/CPI/PPI/工业增加值等发布稿 — 免登录（结构化序列走 macro-data 的 API）
- 中国人民银行 http://www.pbc.gov.cn — 社融/M2/LPR 等货币金融数据发布 — 免登录
- 海关总署 http://www.customs.gov.cn — 进出口总量与分商品数据发布 — 免登录

### 政策

- 工信部 https://www.miit.gov.cn — 产业政策原文、部分行业运行数据 — 免登录
- 发改委 https://www.ndrc.gov.cn — 宏观政策、价格调整与项目批复 — 免登录

### 估值

- 中证指数 https://www.csindex.com.cn — 指数市盈率等估值参考 — 免登录
- 百度股市通（经 AKShare 接口取数）— 个股 PE-TTM 等行情估值 — 免登录；取数后按下方「取数快照」落成 DOCX，时点必须记到收盘日

### 行业数据（汽车行业，2026-10-24 定）

- 乘联会 https://www.cpcaauto.com — 乘用车月度零售批发销量快报，当月即发 — 免登录
- 中汽协 http://www.caam.org.cn — 汽车产销与出口 — 免费统计栏目可用，详细数据会员制
- 中国信通院 http://www.caict.ac.cn — 通信/数字经济白皮书与专题数据 — 免登录

## 取数快照（2026-10-25 定）

任何要进报告的网页或 API 数据，取到后都不能只活在当次报告里，要落成快照进知识库，下次写报告直接引用锚点。有原件的存原件，没有原件的建快照。

1. 写 spec JSON，字段见 `src/snapshot.py` 文件头注释（out、title、org、url、fetched_at、rows、note）
2. `python -m src.snapshot spec.json` 生成 DOCX，out 写 `raw/reports/数据快照/<机构>_<主题>快照_<取数日期>.docx`，如 `国家统计局_宏观数据快照_20261024.docx`
3. 快照不进 raw/inbox、不走 `manage.py sort`。sort 只有研报、财报、政策三类，快照走进去会被拼成「研报」字样或丢掉机构名。落盘后交主线直接 `python manage.py ingest --all`

快照正文必须写全来源机构、来源网址、取数时点。估值快照的取数时点写到收盘日，正文注明跨期不可直接比较。网址确实拿不到时写「未记录」，不许编。

## 自扩展

表内源搜不齐时用 web-research / web-access 外搜，找到确实好用的源后验证一次，把「网址 + 一句话用途 + 登录要求」追加进对应分类，下次取料直接走固定路径；追加时在回复里向用户提一句。

网页端有网络检索兜底源 `web_search`（`src/fetcher.py`）：专用源取不到的非年报缺口会自动改用它，检索网页、抓正文摘录、落快照 DOCX 后摄入，锚点为快照块号；抓取成功的来源网址自动记入 `data/web_sources.json`，这就是程序侧的「外部搜索网址」清单。检索结果只是网页摘录，引用前点原网址复核，数字仍以原网页为准。

## 与其他技能的分工

- macro-data：宏观/财经结构化序列走 API（AKShare、统计局新 API、FRED 等）。已在本机 Win10 适配并全源实测（2026-10-24），conda 环境 macro-data；跑数前关 VPN，详见该技能网络前提
- pdf / md-to-docx：下载后与产出环节的文件处理
- industry-report：本清单是研报生成流程第 1、3 步（搜数据、取料）的固定来源
- src/fetcher.py 与 /fetch 页：网页端免登录源自动化入口。统计局 API、AKShare、东财研报中心、巨潮公告可自动取数并落快照；慧博只借免登录榜单（新财富排名），下载走东财；遇到登录墙（发现报告积分等）只提示用户手动上传或到会话里派资料员，不自动填凭据、不碰验证码
