# 研报结构与版式规范

本文件供 industry-report 定大纲时参考。原 earnings-analysis 的 report-structure，2026-11-04 并入，删去美股专用格式，按 A 股与港股披露习惯改写。下方问答框架段自 2026-11-06 起不再被程序读取，业绩点评问答改读 earnings-review 技能的同类标记段；两处内容如需修改，以 earnings-review 为准。

## 问答速用框架（业绩点评）

业绩点评类问题按以下顺序组织答案，不套整份报告的页面模板。

1. 先给结论，本期业绩超预期、符合预期还是低于预期，用库内数字说明差在哪里。
2. 拆收入，按业务、地区或产品解释增长来源，同比与环比分开说。
3. 拆利润，看毛利率、费用率、净利率的变化，指出主要驱动与拖累。
4. 看关键经营指标，销量、订单、产能利用率、用户数、客单价等，按行业选择。
5. 对照公司指引与市场预期，说明差距和原因；没有指引就明说没有。
6. 更新投资含义与风险，只写库内材料支持的判断。

问答只借用这个组织顺序。事实、数字、评级、目标价必须来自给定页面并带锚点。本文件模板里的示例数字与格式不得写进答案。

## 一、报告整体结构

一份完整的业绩点评按以下顺序展开，页数按材料多少合并或拆分，结论页与财务分析不能省。

1. 业绩摘要与评级
2. 详细业绩分析
3. 关键经营指标与指引
4. 投资逻辑更新
5. 估值与盈利预测
6. 附录

## 二、第一页 业绩摘要

### 页首信息

写清公司名称与代码、报告期、报告日期、评级、当前价、目标价。目标价调整要写旧值到新值，未调整写维持。

### 摘要框

用一张小表给出本期实际、此前预测、市场一致预期与差异。

| 项目 | 实际 | 此前预测 | 差异 |
|---|---|---|---|
| 营业收入 |  |  |  |
| 归母净利润 |  |  |  |
| 扣非归母净利润 |  |  |  |
| 每股收益 |  |  |  |

表下给三到四条要点，每条一句话。第一条说业绩结论，第二条说收入，第三条说利润，第四条说评级与目标价。

### 投资影响

用三到四段展开，每段以加粗判断句开头，后接数据与解释。段落之间不重复摘要框里的数字。

- 业绩超预期或低于预期，主要由哪个业务、地区或产品驱动
- 毛利率或费用率变化，经营的杠杆或压力来自哪里
- 指引上调、维持还是下调，隐含什么
- 评级与目标价是否调整，理由是什么

### 盈利预测更新表

列出本期实际、全年预测、下一年预测，至少包含营业收入、营收增速、毛利率、归母净利润、净利率、每股收益、PE。表底写来源与预测口径。

## 三、第二到三页 详细业绩分析

### 收入分析

- 总收入超预期或低于预期的原因
- 按业务、地区、产品拆分
- 同比与环比趋势
- 与公司指引对照

季度收入序列表按最近四个季度排列，列出总营收与各分部，最后两列给同比与环比。

### 盈利能力分析

- 毛利率变化与驱动
- 费用率与经营利润率
- 利息、税项、非经常性损益等线下项目
- 归母与扣非的差异调节

利润率表按最近四个季度列毛利率、经营利润率、净利率，表下用加号与减号列正向和负向驱动。

### 图表

这一部分配两到三张图，季度收入、季度归母净利、利润率趋势各一张。图题写在图上方，来源写在图下方。

## 四、第四到五页 关键指标与指引

### 经营指标

按行业选择指标，汽车看销量、单车均价、新能源占比、出口占比；消费看门店数、客单价、复购；制造看产能利用率、订单、库存。列出最近四个季度、同比、此前预测与差异。

### 指引与展望

- 公司给了什么指引，区间与口径
- 与此前指引比较
- 与市场一致预期比较
- 实现的可能性与关键假设

有指引时用对照表列新指引、旧指引、变化、市场预期，表下给一句判断。没有指引就写公司未披露，不替公司编指引。

## 五、第六到七页 投资逻辑更新

逐条检验原投资逻辑，每条给状态：强化、不变、削弱。状态后面写本期数据如何支持或挑战这条逻辑，一段一百到二百字。

风险更新写新增风险、原有风险是缓解还是恶化。没有变化就写没有变化，不凑字数。

配一到两张图，估值历史分位、盈利预测调整对比。

## 六、第八到十页 估值与盈利预测

### 估值更新

先给相对估值。可比公司表列市值、PE、PB、EV/EBITDA、营收增速、净利增速，说明可比公司选择理由。再给公司自身历史估值区间与当前分位。有条件再做绝对估值，写清 DCF 的收入增速、利润率、永续增长率、WACC 假设。

目标价方法要写清权重，例如 DCF 占多少、PE 占多少、EV/EBITDA 占多少，并给对应上行或下行空间。估值结论不写成保证。

### 盈利预测明细

至少给本年与下一年，收入按业务拆分，列毛利率、EBITDA、经营利润、归母净利、每股收益、PE、EV/EBITDA。表底写预测来源与日期。

配一到两张图，PE 或 EV/EBITDA 历史区间、目标价推导路径。

## 七、附录

按需放季度模型、业绩会问答要点、同业对比。没有材料就删掉，不留空节。

## 八、版式要求

- 第一页必须有评级、目标价、当前价、预测更新表与三到四段投资影响
- 所有表格表底写来源，表头加底纹，数字右对齐
- 所有图表图题在上、来源在下，编号全文连续
- 实际值与预测值分开标记，实际用 A，预测用 E
- 行文先给数字再给解释，例如“营收同比增长 15% 至 120 亿元”，不写“营收增长强劲”
- 正文不裸露锚点，统一转上标引注，文末列注释表
- 不写“行业领先”“技术雄厚”这类没有数据支撑的形容词
- 评级、目标价、风险提示三件套齐全，评级含义与免责声明按报告模板保留
