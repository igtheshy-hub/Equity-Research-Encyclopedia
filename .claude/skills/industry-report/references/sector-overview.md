# 行业全景报告框架

本文件供 industry-report 技能定大纲时查漏补缺。原 sector-overview 技能，2026-11-04 并入行业研报技能，不再单独作为技能加载。

## 用途与边界

行业全景报告回答一个行业怎么运转、钱在哪里、谁在赚钱、未来往哪走。适合行业首次覆盖、行业深度、主题研究和内部知识建设。单一公司的深度报告不走本框架，用 company-report。

## 第一步 界定范围

动笔前先定五件事。

- 行业与细分：研究哪一层，边界画在哪里，上游、中游、下游是否都算
- 目的：客户报告、内部研究、路演材料，还是选题储备
- 深度：全景概览控制在 5 到 10 页，深度报告 20 到 30 页
- 角度：中性全景，还是带主题判断，例如智能化、出海、国产替代
- 样本：只覆盖上市公司，还是把非上市头部企业也纳入

## 第二步 市场概览

### 市场规模与增速

- 总市场规模的口径与来源，写清统计范围、年份、币种
- 近五年复合增速，标明起止年份
- 未来增速与关键假设，预测必须注明是预测
- 市场拆分：按产品、地区、下游、客户类型

### 行业结构

- 集中还是分散，CR5 与头部份额
- 产业链价值分布，利润集中在哪个环节
- 商业模式：订阅、交易、授权、服务、制造代工
- 进入壁垒：资本、牌照、技术、渠道、网络效应

### 趋势与驱动

- 三到五条长期顺风
- 逆风与风险
- 技术替代路径
- 监管与政策变化
- 并购与产能整合

### 公司画像

|---|---|---|---|---|---|
|  |  |  |  |  |  |

每家公司写清业务描述、战略定位与护城河、近期动态（业绩、并购、新品）、估值快照（PE、EV/EBITDA、EV/Revenue）。估值倍数注明静态、TTM 还是预测期。

### 竞争动态

- 靠什么竞争：价格、产品、服务、渠道
- 谁在抢份额，谁在丢份额，原因是什么
- 新进入者或相邻玩家的替代风险

## 第四步 估值背景

- 行业当前与历史估值区间
- 溢价与折价的驱动：增速、利润率、市场地位
- 近期并购交易倍数
- 与全市场估值比较

## 第五步 投资含义

- 风险收益比最好的环节在哪里
- 哪些主题判断可以通过这个行业表达
- 行业里的核心分歧，多空各自论据
- 可能改变行业叙事的催化剂

## 第六步 输出

报告或演示文稿至少包含市场概览与规模、竞争格局图、公司对比表、估值汇总，以及市场增长、份额变化、估值历史三类图表。附表放公司明细数据。

## 数据与写作纪律

- 市场规模必须写来源与统计口径，区分总市场规模与可及市场
- 行业数据老化快，标注取数日期，过期数据明确提示
- 图表优先于文字，市场规模瀑布图、竞争定位矩阵、估值散点图各有用处
- 每个数字带库内锚点，外部数据先落快照再引用；没有锚点的数字列缺口，不写进正文
- 判断与事实分开写，预测句必须有“预计”“测算”字样并交代假设
