# 竞争格局分析框架

本文件供 industry-report 写竞争格局章节时参考，也供公司研报的行业空间与竞争格局节使用。原 competitive-analysis 技能及其 frameworks、schemas 两个参考文件，2026-11-04 合并并入。

## 一、先定范围

竞争分析对不同人有不同含义，动笔前先定四件事。

- 对象：单一目标公司加周围竞对，还是多家公司平铺对比、没有主角
- 竞对集合：用户点名就用点名的公司；用户说“常规几家”时先提一组再确认
- 深度：给熟悉行业的人做快速判断，还是给新人做完整入门；后者需要市场规模、行业经济与历史
- 投资语境：是否需要乐观、中性、悲观三种情景与验证信号；战略复盘不需要

用户给了竞对数据表时，先确认列与指标怎么对应。原始数值照抄，不重算、不重新四舍五入。

## 二、行业关键指标

先定这个行业真正用来比较的三到五个指标，所有竞对用同一套口径。

| 行业 | 常用指标 |
|---|---|
| 软件与 SaaS | ARR、净收入留存率、获客成本回收期、LTV/CAC、40 法则 |
| 支付 | 交易额 GPV、费率 take rate、附加率、交易毛利 |
| 平台与电商 | GMV、take rate、买卖比、复购率 |
| 零售 | 同店销售、库存周转、坪效 |
| 物流 | 业务量、单票成本、准时率、产能利用率 |
| 汽车 | 销量、单车均价、新能源占比、出口占比、产能利用率 |
| 制造 | 产能利用率、订单、库存周转、单位成本 |

表里没有的行业，选投资人和经营者实际用来比较的指标，不堆通用财务比率。

## 三、市场背景

给规模、增速、驱动与逆风，每项带来源与年份。正确写法是“2025 年国内新能源乘用车渗透率达到 XX%，较上年提升 X 个百分点（来源，日期）”，不写“市场空间广阔、增长迅速”。

## 四、行业经济

讲清价值怎么流动，按行业结构选画法。

- 垂直结构：产业链分层，每层的典型毛利率
- 平台与网络：生态参与者，价值在谁与谁之间流动
- 分散行业：整合动力，规模带来的成本差

## 六、竞对分组

按最适合行业的一种视角分组，不混用。

- 按商业模式：平台、垂直、综合
- 按客户：大企业、中小企业、个人
- 按身位：直接竞争、相邻进入、新兴玩家
- 按出身：传统龙头、颠覆者、新进入者

## 七、定位可视化

| 形式 | 适用 |
|---|---|
| 2×2 矩阵 | 有两个主导竞争维度 |
| 雷达图 | 多维度对比 |
| 梯队图 | 自然形成战略分组 |
| 产业链图 | 垂直行业 |
| 生态图 | 平台市场 |

2×2 矩阵常用轴对：技术与 SaaS 用产品广度乘客户群、集成深度乘地域覆盖；消费与零售用价格带乘产品线、线上乘线下；金融用产品复杂度乘客户专业度、规模乘专业化；医疗用服务场景乘支付方、技术赋能乘服务广度；工业用定制化程度乘规模、地域范围乘垂直聚焦。

## 八、竞对深挖

每家两张表。

指标表列营业收入、增速、毛利率、市值、净利润或 EBITDA、客户数或销量、市场份额。

定性表列业务一句话、优势两三条、劣势两三条、当前战略重点。

## 九、横向对比

用同一张表列各公司在规模、增速、利润率、份额等维度的表现。评分可以用圆点加数值，例如“●●● 1600 亿元”，不能只给圆点不给数。

## 十、战略背景

写并购交易、合作趋势、融资节奏、监管变化。并购表列买方、标的、日期、交易金额、倍数、逻辑，倍数注明是 EV/Revenue 还是 EV/EBITDA。

情景表列乐观、中性、悲观三种情景，给概率、估值与关键假设，假设必须可量化。

## 十一、综合判断

护城河逐项评级，强、中、弱三档。

| 护城河 | 看什么 |
|---|---|
| 网络效应 | 用户与供给的飞轮强度，跨边还是同边 |
| 转换成本 | 技术集成深度、合同锁定、使用习惯 |
| 规模经济 | 量产后的单位成本优势，最小有效规模 |
| 无形资产 | 品牌、数据、牌照、专利 |

最后回答三件事：哪些优势难以复制，哪些结构性弱点难以修复，当前状态与变化方向如何。

## 十二、数据与写作纪律

- 所有竞对指标取同一会计期间，例外要标明，例如“2025FY”与“2026H1”
- 同一指标在各家公司用同一定义
- 跨境比较换算成人民币或美元，写明汇率与日期
- 缺失数据写“—”或“N/A”，估计值加“E”标记，不留空
- 每个数字带来源与日期，库内材料带锚点
- 图表标题写判断，不写“竞争分析”这类栏目名
- 图表是真图表，不用排版表格冒充
- 颜色控制在两到三种，全篇含义一致
