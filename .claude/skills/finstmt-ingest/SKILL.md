# 财报摄取（v1.0，已接入程序）

状态：已实现。本文件自 schema/财报摄取-skill.md 迁入（2026-10-29，唯一副本），参考文档随迁（01、03 在本目录 references/，02 归 finstmt-qa）。实现产物：src/filing.py（四段式流程，ingest_one 对 filing 类自动分流）、src/fin_calc.py（勾稽与指标计算器）、schema/filing_items.json（机器可读科目别名表）、data/fin/（结构化存储）。本文件是摄取 skill 的流程指令，引用三份参考文档：
- references/财报摄取-01-科目字典.md（科目清单、数据字段、勾稽校验）
- .claude/skills/finstmt-qa/references/财报摄取-02-两岸术语映射.md（口径陷阱，属问答技能，旧格式科目归一规则引自它）
- references/财报摄取-03-多口径指标字典.md（派生指标公式与报告期处理）

## 口径定位（先读，防混淆）

本流程原生口径是 A 股（大陆企业会计准则，科目字典 version 2019b）。A 股财报（年报、季报）直接套用，不需要任何口径转化；坊间印象里「skill 是港股口径、A 股要靠三份文档转化」是反的。港股财报才是被兼容的特例：

- 以人民币列示的港股报表：科目名经 filing_items.json 别名表归一（如「權益總額」→「所有者权益合计」），费用与负债的括号减项由 `_fix_statement_signs` 翻正，权益变动表口径不同导致 R3 跳过
- 以港元列示的港股报表：整份拒收（UnsupportedFiling），改走文本编译，不产结构化行

三份参考文档的分工：01 是 A 股科目字典本体（含港股与旧格式别名，references/ 内）；02 是台湾 IFRS 术语到 A 股科目的映射，归 finstmt-qa（references/），摄取层只引其旧格式科目归一规则；03 是派生指标公式字典（references/ 内）。

## 会话内何时用本技能

用：摄入出问题时排查（勾稽失败挂起、[拒] 未抄录到科目、港元拒收、补录后仍缺科目、重摄留重复行）；解释或核对【数据】【指标】【管理层】行格式与口径；把 data/fin 结构化数值与原文对照核数；理解科目归一行为（aliases 命中、字典外科目 listed=false）；目标数据补抄的取舍。

不用：日常摄入不需要会话参与，财报放 raw/filings 后 `python manage.py ingest --all` 自动分流，不要手动模拟流程；报表数字的分析判断、阈值评价归 finstmt-qa；选页问答归 kb-ask。另注意未实现范围：银行、保险、证券专用科目及金融企业指标仍是草案（01/03 号文档标注），摄入金融企业财报前先核对 filing_items.json 覆盖度。

## 1. 定位与职责边界

本 skill 处理已归入 raw/filings/ 的财报（filing 类），产出且仅产出三类客观内容：

1. 科目原值（四表数据行）
2. 派生指标（按指标字典多口径计算）
3. 管理层引述（MD&A、经营讨论、重要事项中的原话，标注语境）
4. 研报目标数据（带目标清单摄入时，按清单补抄的原文数值；见第六步之后的「目标数据补抄」）

以下内容禁止产出：趋势评论、好坏判断、阈值评价、预测、跨期对比的定性描述。同比、单季、TTM 数值本身属于派生指标可以计算，但「增长强劲」「优于同业」之类的表述一律不写。判断类内容归问答 skill（见 .claude/skills/finstmt-qa/SKILL.md）。

## 2. 工作流

### 第一步：识别

从封面、页眉、审计报告页提取：

1. 公司规范名（与 wiki 现有公司页名对齐，对不上按现有归并规则处理）
2. 报告期类型（Q1/H1/Q3/FY）与截止日
3. 报表范围：合并与母公司两套都要抽取，scope 字段区分；母公司科目只进 data/fin 结构化存储，不进 wiki 页面（避免页面膨胀，v1.0 修正）
4. 审计意见类型（标准无保留 / 带强调事项段 / 保留 / 无法表示意见）——客观事实，记入 source 页材料信息
5. 报表格式版本：2018 年及以前的旧格式科目（如「应收票据及应收账款」合并列示）按 02 号文档规则归一，归一不了的保留原科目名并备注「旧格式合并披露」

### 第二步：定位四表

找到合并资产负债表、合并利润表、合并现金流量表、合并所有者权益变动表（及母公司四表）所在页，记录页码区间，后续锚点取自这些页。现金流量表补充资料（折旧摊销明细）若披露，一并定位。

### 第三步：逐表抄录

1. 按 01 号字典顺序逐科目抄录，只抄数不改数，数值带锚点
2. 字典外科目：保留原文科目名，listed=false，不猜测映射
3. 缺失科目：跳过并记入缺失清单，不留空、不估数
4. 单位按披露记录，抄录后统一换算为元

港股年报的列示习惯与 A 股不同，抄录后做两步机械规整：报表若以港元列示，整份不套 A 股四表流程，抛 `UnsupportedFiling` 改走文本编译；以人民币列示的照常入库，但费用与负债总额常写成括号减项，`_fix_statement_signs` 在勾稽前统一翻正（收入为正、成本为负即判定为港股列示）。港股权益变动表口径与 A 股不同，R3 跳过并在日志注明。

### 第四步：勾稽校验

跑 01 号字典 R1—R4 四条规则，容差取 config.ingest.filing_check_tol，当前 0.005，即相对误差 5‰。任一失败：整份报表数值挂起，不入库，错误清单交审校；不自动修数。部分勾稽依赖的数据缺失（如季报无补充资料）时，对应规则跳过并记录，不影响其余校验。

实现注记（v1.1）：R4 已实现，由 src/filing.py `_supp_net_profit` 从现金流量表补充资料页机械解析「净利润」行的本期金额，取不到或报表单位未识别时跳过；R1、R2（含期末−期初子校验两条）、R3（容差放宽 5 倍）见 src/fin_calc.py `check_reconciliations`。

实现注记（v1.2）：主要会计数据页缺资产总计、负债合计、所有者权益合计、营业收入、净利润时，自动重抄关键页补录一次；同名科目按报表归属优先，现金流量表的存货调整行不会冒充资产负债表存货；同一份财报重摄时，先清掉该报告期由它派生的旧行再并入，避免名称归一或符号修正后留下重复行。

### 第五步：派生计算

1. 按 03 号字典计算派生指标，多口径全算，每条带口径标签
2. 分母或科目缺失的指标跳过，记入缺失清单；按字典规则允许近似的（如 ROIC 利息费用以财务费用近似）打 degraded 标签
3. 报表披露值（加权平均 ROE、银行 NIM 等）直接摄取，派生口径并存不覆盖

### 第六步：管理层引述提取

从 MD&A / 董事会报告 / 重要事项中提取：经营情况说明、会计政策变更、业绩指引、风险因素的原话。逐条带锚点，标注语境（指引 / 政策变更 / 风险提示）。营销性、样板性、免责性文字丢弃。引述是「公司说了什么」的事实，不是本 skill 的观点。

### 目标数据补抄（v1.3，仅带目标清单时）

首页关注点、取数任务与研报管线补定期报告都会带目标清单（研报取的是本次勾选的数据缺口，文档类缺口不进清单）。除四表抄录外，按目标清单再跑一轮：定位目标数据所在的页，加上主要会计数据页与 MD&A 页，逐条抄原文数值，记 `item`、`scope`（年度与口径）、`value`、`unit`、`page`、`quote`。

- 原文没有的目标不输出，不用相近指标顶替，不估算，不换算单位
- 目标数据不进 `filing_items.json` 科目字典，不参与勾稽；勾稽仍只看四表科目
- 与四表已抄科目同口径同数值的行略过，避免同一数字写两遍
- 目标行随公司页「经营与财务」节落库，同时存进 `data/fin/<公司>.json` 的 `periods[报告期].targets`
- 港股以港元列示的财报仍抛 `UnsupportedFiling` 改走文本编译，目标数据按关注点提炼，不产目标行

### 第七步：落库

公司页「经营与财务」节按固定行格式追加（见第 3 节），旧数据行不删改，同公司新报告期只增行。source 页按现有规则生成，材料信息含报告期、审计意见、条目数。manifest 记录沿用现有字段。

## 3. 行格式契约（wiki 页内的结构化行）

 wiki 正文一行一条，固定语法，供程序与问答层解析：

- 科目行：【数据】报告期 scope 科目 = 数值元 [[锚点]]
  例：【数据】2026H1 合并 营业收入 = 81,580,000,000 元 [[某某公司2026半年报.pdf#p7]]
- 指标行：【指标】报告期 指标名(口径标签) = 数值 [[锚点]][[锚点]]
  例：【指标】2026H1 ROE(归母平均) = 0.172 [[半年报.pdf#p7]][[半年报.pdf#p60]]
  锚点取该指标取数科目的锚点集合。披露值口径标签写「披露」。
- 目标数据行：【数据】报告期 目标 数据名（口径） = 数值 单位 [[锚点]]
  例：【数据】2025FY 目标 研发投入（2023-2025年） = 50 亿元 [[吉利汽车财报_20251231.pdf#p30]]
  只由带目标清单的摄入产生，数值与单位照原文，不换算
- 引述行：【管理层】「原话」——语境 [[锚点]]
- 缺失记录：不写入页面，只在 source 页材料信息下列缺失清单（科目与指标分列）

行格式合法性由程序校验（正则可解析、数值可读、锚点真实），违规行丢弃并计数，沿用现有锚点校验机制。

## 4. 幂等与重复

同一文件 SHA256 一致跳过（现有机制）。同一报告期不同来源文件（如正式年报与更正版）：按文件分别摄取，数据行并存，source 页各自记录；审校阶段人工裁决冲突。
