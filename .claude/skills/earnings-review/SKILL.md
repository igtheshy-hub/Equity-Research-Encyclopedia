# 业绩点评（v1.0，网页问答已接入）

本技能是业绩点评的组织规范，不提供事实与数字。输入是用户问题与知识库页面，输出是借用固定组织顺序写成的点评；事实、数字、评级、目标价只能来自给定页面并带锚点。

## 1. 网页问答的接入方式

`src/ask.py` 的 `_method_block()` 在问题命中业绩点评时，现读 `references/report-structure.md` 里 `<!-- QA-FRAMEWORK:START/END -->` 标记段，原样注入答题提示词。只注入标记段，不加载全文；标记段丢失时不注入框架，答题仍按通用规则走。改标记段即改网页端业绩点评的答题结构，热重载会覆盖 skill 目录下的 md 改动。

## 2. 问答组织顺序

1. 先给结论，本期业绩超预期、符合预期还是低于预期，用库内数字说明差在哪里
2. 拆收入，按业务、地区或产品解释增长来源，同比与环比分开说
3. 拆利润，看毛利率、费用率、净利率的变化，指出主要驱动与拖累
4. 看关键经营指标，按行业选择销量、订单、产能利用率、用户数、客单价等
5. 对照公司指引与市场预期，说明差距和原因；没有指引就明说没有
6. 更新投资含义与风险，只写库内材料支持的判断

详细版式与表格要求见 `references/report-structure.md` 标记段之后的部分。

## 3. 边界

- 财报分析类问题叠加 finstmt-qa 的财报纪律；本技能只管点评的组织顺序与版式
- 数字必须带口径与报告期，句尾锚点只能复用页面中出现过的
- 不做盈利预测以外的推断；预测数字标「预计」并交代假设
- 不写「行业领先」「技术雄厚」这类没有数据支撑的形容词

## 4. 与其它技能的分工

- finstmt-qa：财报数据的分析纪律与判断阈值
- company-report：公司深度研报的八节框架
- industry-report：行业研报框架
- 本技能：业绩点评的问答顺序与点评版式
