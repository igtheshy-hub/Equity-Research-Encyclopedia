# 研报百科

给投研团队用的 LLM Wiki 知识库：把券商研报等材料沉淀成句句标注来源文件和页码、越用越厚、可审可查的团队百科。刻意不走 RAG 路线，知识以 wiki 页面形式沉淀，而不是问完即弃的检索。

## 目录结构

- `raw/` 原始资料层（人工管理，程序只读）：`reports/` 卖方研报按行业分目录、`filings/` 上市公司财报按公司分目录、`policies/` 监管政策文件
- `wiki/` 维基知识层（程序维护）：`index.md` 总索引、`log.md` 操作日志、`companies/` 公司页、`industries/` 行业页、`concepts/` 概念页、`sources/` 来源摘要页（每份材料一页，摄入时自动生成）
- `schema/CLAUDE.md` 知识库操作规范（格式、锚点语法、各环节规则）
- `outputs/` 查询产出：研究备忘、对比分析、审校报告
- `data/` 内部状态：摄入清单、逐页文本、LLM 调用日志

## 快速开始

1. 复制 `.env.example` 为 `.env`，填入智谱 API Key
2. 把研报 PDF 放进 `raw/reports/<行业>/`（文件名全库唯一，建议带券商、主题和日期）
3. 体检：`python manage.py selftest`
4. 摄入：`python manage.py ingest --all`（或先 `--dry-run` 预览提取效果）
5. 问答：`python manage.py ask "贵州茅台 2024 年营收多少"`
6. 审校：`python manage.py audit`
7. 界面：`python manage.py serve` 后浏览器打开 http://127.0.0.1:5000

## 机制

三个环节都由大模型参与、由确定性程序把关：

- 摄入：逐页提取 PDF 文本，LLM 编译成一句一条、句尾带 `[[文件名.pdf#p页码]]` 锚点的知识条目，程序归并进主题页，并在 `wiki/sources/` 生成该材料的来源摘要页。合并只追加不删除，锚点集合只增不减，写盘前程序校验
- 问答：两步。先凭索引选页，再用所选页全文作答，逐句带锚点。选页为空直接回答不知道，不依赖模型自觉；答案锚点程序校验，违规重试一次后降级标记
- 审校：矛盾（附双方原文）、过期、未摄入、孤立四类健康报告，存 `outputs/`

详细规范见 `schema/CLAUDE.md`。

## 已知限制

扫描版 PDF 无文本层会被拒绝（无 OCR）；双栏排版与表格的文本流可能乱序，靠点角标对照 PDF 原页人工抽查兜底；选页只看索引摘要（无向量检索，刻意取舍）；矛盾检测是待人工复核清单而非结论；Flask 为本地单机原型。
