## 1. 定位与职责边界

本 skill 是第二部分，分析判断层。输入是用户问题加 wiki 里的客观数据（【数据】【指标】【管理层】行），输出是带立场的分析判断。判断内容默认只呈现给用户，经用户确认后才沉淀进 wiki（复用现有会话提取机制：模型提案、用户勾选、写入记「会话中提取」）。

三条硬边界：

1. 库里没有的信息回答「知识库中没有该信息」，不用模型自身知识补全（现有 Query 规则，此处重申）。同业对标需要库外同业数据时，列出待查清单而不是现编数字。
2. 引用任何派生指标必须带口径标签与报告期；中途换口径必须说明理由。
3. 引用判断阈值必须注明出处（张明辉，源自该 skill），且按 02 号文档陷阱三说明台湾经验值在 A 股的适用限度。

## 2. 分析工作流

用户提问不限于此顺序，但完整性分析按以下六步走。每步先盘数据再下判断，数据缺失时明确说缺、判断降级或不给。

### 第一步：数据盘点

从公司页收集相关报告期的全部【数据】【指标】【管理层】行，列出口径清单与缺失清单。多期数据并排（本期 / 上年同期 / 单季序列）。

### 第二步：资产负债表体检

1. 结构：资产大类占比，应收票据及应收账款、存货、固定资产、商誉、货币资金的相对重量；无形资产与商誉偏高的标记并购减损风险待查
2. 周转：DSO、DIO、DPO（声明口径，含票据与否）与 CCC，对照阈值（DSO < 90 天、DIO 30—60 天且 < 20 天可疑，出处注明），异常项进第六步地雷复核
3. 杠杆：资产负债率对照产业校准线（台湾经验值仅作参考，按 A 股行业实际分布调整，明说调整依据）
4. 流动性：流动比率、速动比率，注意 02 号文档陷阱二（货币资金含受限资金）

### 第三步：损益表体检

1. 成长：营收与归母净利的累计同比与单季同比，单季波动单独看
2. 盈利结构：毛利率、核心营业利润率（自定义口径，注明）、营业利润率（宽口径）、净利率分层看，说明核心与宽口径的差异来源（投资收益、减值、其他收益）
3. 费用：销售、管理、研发费用率变动，研发费用绝对额与趋势（研发下降本身是信号）
4. 非经常性：扣非与归母的差额，一次性损益占利润比重

### 第四步：现金流量表体检

1. 获现比（经营净额 ÷ 净利润）持续低于 1 是盈利质量警报
2. FCF 口径选择要声明（标准 / 严格），与股利支付能力对照
3. 三大活动净额的组合形态（经营正、投资负、筹资负的成熟型等）
4. 经营净额与净利润的长期背离 = 地雷特征五的前置信号

### 第五步：比率与对标

1. ROE 拆解：杜邦三因子（净利率 × 总资产周转率 × 权益乘数），说明 ROE 靠什么挣来
2. ROIC 对比 WACC：WACC 参数（Beta、无风险利率、风险溢价）是外部输入，计算时列明取值与来源，结论标注参数敏感性
3. 同业对标：库内有同业页则对比，没有则列待查清单

### 第六步：地雷检查

六大特征逐项过数（每项给数值与阈值对照，缺数标「无法核验」）：DSO 过高、DIO 过低、应收存货应付同时异常增长、毛利率偏离同业、自由现金流长期为负、OCI 异常大。六大警讯（高管与会计师更换、检调、抽银根、质押）属库外信息，只列「待查项」不编造。命中两项以上时结论升级并建议人工核查附注。

### 第七步：结论与沉淀提案

1. 结论按证据强度分层：数据支持充分 / 部分支持 / 数据不足不下结论
2. 每条判断句内嵌依据：指标@口径@报告期加锚点
3. 沉淀提案格式：【观点】判断句（依据：指标@口径@报告期 [[锚点]]；判断：YYYY-MM-DD 会话提取）
4. 已提取过的行不再重复呈现（现有机制）

## 3. 产业校准

七大产业框架（电子组装、IC 设计、实体通路、连锁餐饮、生技医疗、银行、保险）作为参考知识随本 skill 维护，A 股行业映射与本土基准值待按实际数据校准后补入（当前只有台湾参考值，引用时按 02 号文档陷阱三处理）。银行保险分析时切换金融专用指标（NIM、不良率、拨备覆盖率、已赚保费等），定义见 03 号字典 3.8。

## 4. 沉淀与老化

1. 【观点】行进公司页需要节位置：建议在页节枚举中新增「分析观点」节（涉及一处代码改动，定稿时一并处理），过渡期放「其他」节
2. 观点行带判断日期与依据数据期。lint 增加一条：公司页出现更新报告期的【数据】行后，依据期早于该期的【观点】行标记待复核
3. 观点冲突不自动删除：新旧观点并存，由审校裁决（沿用矛盾检测机制）
