# 财报摄取·多口径指标字典（草案 v0.1）

状态：讨论稿，未接入程序。定稿后作为派生指标的计算规范。
日期：2026-10-12

前置：科目与取数以 01 号文档科目字典为准；公式中的台湾术语已按 02 号映射表换算为 A 股科目。

## 1. 原则

1. 多口径并存：同一指标的不同口径是独立条目（如 ROE-平均、ROE-期末、ROE-归母平均、ROE-TTM），每条带口径标签入库，数值全部机械计算，不涉及判断。
2. 引用纪律：问答层（第二部分）引用任何派生指标，必须声明口径标签；分析结论变更口径时要说明理由。
3. 披露值优先：报表自身披露的比率（加权平均 ROE、银行 NIM、不良率、拨备覆盖率等）作为原值摄取，派生口径仅作补充，两者并存但不互相覆盖。
4. 摄取层不算判断类指标：一切含阈值、评级、好坏结论的内容不进本字典，归问答层。

## 2. 报告期处理规则（所有流量指标的前置）

A 股利润表与现金流量表披露的是年初至今累计值，处理规则：

1. 累计原值：按报表披露原样入库，period_type 记 Q1/H1/Q3/FY。
2. 单季拆分：Q1 本身即单季；其余单季 = 本期累计 − 上一报告期累计；Q4 = 年报 − 三季报。
3. TTM（滚动十二个月）= 本期累计 + 上年年报 − 上年同期累计。
4. 时点数（资产负债表科目）不做差分，只做期末值对比与期初期末平均；平均口径 =（期初 + 期末）÷ 2，期初取上年年报期末值。
5. 年化天数：周转天数类指标一律用 TTM 流量 × 365 计算（年报可用全年累计），季报禁止用累计值直接乘 365。

## 3. 指标条目

格式：条目名（口径标签）= 公式｜取数说明。

### 3.1 获利能力

- 毛利率（累计/单季/TTM）=（营业收入 − 营业成本）÷ 营业收入｜三种报告期各算一条。
- 核心营业利润率（自定义派生）=（营业收入 − 营业成本 − 税金及附加 − 销售费用 − 管理费用 − 研发费用 − 财务费用）÷ 营业收入｜对齐台湾营业利益口径的构造值（02 号文档陷阱一），标签注明自定义。
- 营业利润率 = 营业利润 ÷ 营业总收入｜A 股宽口径，与上一条区分。
- 净利率 = 净利润 ÷ 营业总收入；归母净利率 = 归母净利润 ÷ 营业总收入。
- ROE-加权（披露值）= 报表披露的加权平均净资产收益率｜原值摄取。
- ROE-期末 = 净利润 ÷ 期末所有者权益合计（年报口径即全面摊薄）。
- ROE-平均 = 净利润 ÷（期初 + 期末）所有者权益合计 ÷ 2。
- ROE-归母平均 = 归母净利润 ÷（期初 + 期末）归母所有者权益 ÷ 2。
- ROE-TTM = 净利润 TTM ÷ 归母所有者权益平均。
- ROA-平均 = 净利润 ÷（期初 + 期末）资产总计 ÷ 2。
- ROIC =（利润总额 + 利息费用）×（1 − 有效税率）÷ 投入资本；有效税率 = 所得税费用 ÷ 利润总额；投入资本 = 有息负债（短期借款 + 一年内到期的非流动负债 + 长期借款 + 应付债券 + 租赁负债）+ 所有者权益合计｜利息费用取财务费用附注，缺附注时以财务费用近似并打 degraded 标签。

### 3.2 杠杆

- 资产负债率 = 负债合计 ÷ 资产总计｜时点。
- 长期负债比率 = 非流动负债合计 ÷ 资产总计｜时点。
- 权益乘数 = 资产总计 ÷ 所有者权益合计｜时点。

### 3.3 流动性

- 流动比率 = 流动资产合计 ÷ 流动负债合计。
- 速动比率 =（流动资产合计 − 存货）÷ 流动负债合计。
- 保守速动比率 =（货币资金 + 交易性金融资产 + 应收票据 + 应收账款）÷ 流动负债合计｜严口径变体。

### 3.4 效率（周转天数）

- DSO-期末 =（应收账款 ÷ 营业收入 TTM）× 365；DSO-平均 =（（期初 + 期末）应收账款 ÷ 2 ÷ 营业收入 TTM）× 365；DSO-含票据 =（应收票据 + 应收账款 + 应收款项融资）口径同上再算一条｜对齐台湾应收账款分析时用含票据口径（02 号映射表）。
- DIO-期末 / DIO-平均 / DIO-含发出商品省略（A 股报表不单列发出商品于存货外）=（存货 ÷ 营业成本 TTM）× 365｜分母是营业成本不是营业收入。
- DPO-期末 / DPO-平均 / DPO-含票据 =（应付账款 ÷ 营业成本 TTM）× 365｜口径变体同 DSO。
- 现金转换周期 CCC = DSO + DIO − DPO｜三个口径标签组合时 CCC 继承各分项标签（如 CCC-平均含票据）。
- 总资产周转率 = 营业收入 TTM ÷ 平均资产总计。

### 3.5 现金流

- 经营现金流净额（累计原值）。
- FCF-标准 = 经营活动产生的现金流量净额 − 购建固定资产、无形资产和其他长期资产支付的现金｜国内通行口径。
- FCF-严格 = 经营净额 − 资本支出 − 偿付利息支付的现金｜对齐 SKILL.md 口径；A 股利润分配与偿付利息合并披露于「分配股利、利润或偿付利息支付的现金」，利息部分需拆分，缺拆分时以财务费用附注利息支出近似并打 degraded 标签。
- 获现比 = 经营活动现金流量净额 ÷ 净利润（TTM 口径优先）｜盈利质量核心指标。
- 股东盈余 = 净利润 + 折旧摊销 − 资本支出｜折旧摊销取现金流量表补充资料，季报常缺，年报口径计算，缺数不硬算。
- 资本支出（原值）= 购建固定资产、无形资产和其他长期资产支付的现金。

### 3.6 成长

- 营收同比 = 本期累计 ÷ 上年同期累计 − 1；营收单季同比 = 本期单季 ÷ 上年同期单季 − 1。
- 归母净利同比、归母净利单季同比｜公式同上，分子换归母净利润。
- 扣非净利同比｜报表披露「扣除非经常性损益的净利润」为原值后再算。

### 3.7 每股

- 基本每股收益（披露原值）；稀释每股收益（披露原值）；EPS-单季 = 单季归母净利润 ÷ 期末股本（近似口径，标签注明）。

### 3.8 金融企业专用

- NIM（披露值优先）=（利息收入 − 利息支出）÷ 生息资产平均｜上市银行按自身口径披露，直接摄取；派生口径（利息净收入 ÷（发放贷款和垫款 + 金融投资平均））作补充，标签注明近似。
- 不良贷款率、拨备覆盖率、核心一级资本充足率（披露原值）。
- 保险：已赚保费、退保金、赔付支出净额为科目原值；寿险新准则指标待补（01 号文档待核实事项）。

## 4. 外部数据指标（不进摄取层）

- P/E、P/B、股息率：依赖股价，财报内无此数据。问答层需要时实时取行情并标注取价时点与来源（中证指数 / 交易所行情），不落库、不进摄取。
- WACC：公式 = 权益成本 × 权重 + 税后债务成本 × 权重（CAPM：无风险利率 + Beta × 市场风险溢价）。Beta、无风险利率、市场溢价均为外部输入，摄收拾取层只备齐 ROIC 所需科目，WACC 在问答层按当次输入计算，参数留痕。

## 5. 单位换算

- 财报原值单位为元；研报常引亿元。派生计算前统一换算为元；比率与天数类指标无单位；展示层可再换算亿元，展示换算不影响存储。
- 百分比指标存储为小数（0.338 表示 33.8%），展示层再格式化。
