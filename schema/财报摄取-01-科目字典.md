## 1. 设计原则

1. 一套统一字典，不按企业类型拆四套模板。财政部 16 号文本身就是把金融专用项以角标并入统一格式，本字典沿用该思路，给每个科目打适用标签：〔通〕通用、〔银〕银行专用、〔保〕保险专用、〔证〕证券专用。
2. 科目以官方行项目名为准，同义异名（如长期股权投资附注的权益法/成本法）只在备注说明，不另立条目。
3. 字典带版本字段（dict_version + 依据文号），格式修订时增量更新，不推倒重来。
4. 摄取层只存报表披露的原值；一切计算（单季拆分、同比、TTM、比率）都在派生指标字典（03 号文档）里按固定口径做。

## 2. 数据载体字段

每条摄取的数值是一个记录，字段如下：

| 字段 | 说明 | 示例 |
|---|---|---|
| company | 公司规范名 | 贵州茅台 |
| period_type | 报告期类型 | Q1 / H1 / Q3 / FY |
| period_end | 报告期截止日 | 2026-06-30 |
| scope | 合并 / 母公司 | 合并 |
| statement | 报表 | 资产负债表 / 利润表 / 现金流量表 / 所有者权益变动表 |
| item | 科目名（以本字典为准） | 应收账款 |
| value | 数值（见单位规则） | 1758000000.00 |
| listed | 是否字典内科目 | true / false |
| anchor | 原文锚点 | [[xxx.pdf#p12]] |
| source | raw/ 相对路径 | raw/filings/贵州茅台/xxx.pdf |
| dict_version | 科目字典版本 | 2019b |

单位规则：财报披露单位通常为元，摄取时按报表实际披露记录，派生计算前统一换算为元；换算规则写进指标字典，不在此处。

## 3. 科目清单

下述清单照录官方行项目（分组排列，行内〔银〕〔保〕〔证〕为金融专用标签，无标签即通用）。

### 3.1 资产负债表（时点数，存量）

流动资产：货币资金、结算备付金〔银〕、拆出资金〔银〕、交易性金融资产、衍生金融资产、应收票据〔证〕、应收账款〔证〕、应收款项融资、预付款项、其他应收款、买入返售金融资产〔银〕、存货、合同资产、持有待售资产、一年内到期的非流动资产、其他流动资产、流动资产合计。

非流动资产：债权投资、其他债权投资、长期应收款〔银〕、长期股权投资、其他权益工具投资、其他非流动金融资产、投资性房地产、固定资产、在建工程、生产性生物资产、油气资产、使用权资产、无形资产、开发支出、商誉、长期待摊费用、递延所得税资产、其他非流动资产、非流动资产合计、资产总计。

流动负债：短期借款、交易性金融负债、衍生金融负债、应付票据、应付账款、预收款项、合同负债、卖出回购金融资产款〔银〕、吸收存款及同业存放〔银〕、代理买卖证券款〔证〕、代理承销证券款〔证〕、应付职工薪酬、应交税费、其他应付款、应付手续费及佣金〔证〕、应付赔款〔保〕、应付退保〔保〕、应付保单红利〔保〕、一年内到期的非流动负债、其他流动负债、流动负债合计。

非流动负债：长期借款、应付债券、保险合同准备金〔保〕、租赁负债、长期应付款、预计负债、递延收益、递延所得税负债、其他非流动负债、非流动负债合计、负债合计。

所有者权益：实收资本（或股本）、其他权益工具（其中：优先股、永续债）、资本公积、减：库存股、其他综合收益、专项储备、盈余公积、一般风险准备〔银〕、未分配利润、所有者权益合计、负债和所有者权益总计。

金融企业细目补充（取自 36 号文，用于〔银〕〔保〕科目展开）：现金及存放中央银行款项、存放同业款项、贵金属、发放贷款和垫款、应收保费、应收分保账款、应收分保合同准备金；保险合同准备金的展开：未到期责任准备金、寿险责任准备金、长期健康险责任准备金。寿险新准则科目（保险服务收入等）待补。

### 3.2 利润表（期间数，流量，披露为年初至今累计值）

营业总收入：营业收入、利息收入〔银〕、已赚保费〔保〕、手续费及佣金收入〔证〕；营业总收入合计。

营业总成本：营业成本、利息支出〔银〕、手续费及佣金支出〔证〕、退保金〔保〕、赔付支出净额〔保〕、提取保险合同准备金净额〔保〕、保单红利支出〔保〕、分保费用〔保〕、税金及附加、销售费用、管理费用、研发费用、财务费用（其中：利息费用、利息收入）；营业总成本合计。

损益调整项：其他收益、投资收益（其中：对联营企业和合营企业的投资收益）、以摊余成本计量的金融资产终止确认收益〔银〕、汇兑收益〔银〕、净敞口套期收益、公允价值变动收益、信用减值损失、资产减值损失、资产处置收益。

利润层级：营业利润、营业外收入、营业外支出、利润总额、所得税费用、净利润（分类：持续经营净利润、终止经营净利润、归母净利润、少数股东损益）、其他综合收益的税后净额（归属母公司/归属少数股东）、综合收益总额、基本每股收益、稀释每股收益。

### 3.3 现金流量表（期间数，流量，披露为年初至今累计值）

经营活动流入：销售商品、提供劳务收到的现金；客户存款和同业存放款项净增加额〔银〕；向中央银行借款净增加额〔银〕；向其他金融机构拆入资金净增加额〔银〕；收到原保险合同保费取得的现金〔保〕；收到再保业务现金净额〔保〕；保户储金及投资款净增加额〔保〕；收取利息、手续费及佣金的现金〔证〕；拆入资金净增加额〔证〕；回购业务资金净增加额〔证〕；收到的税费返还；收到其他与经营活动有关的现金；经营活动现金流入小计。

经营活动流出：购买商品、接受劳务支付的现金；客户贷款及垫款净增加额〔银〕；存放中央银行和同业款项净增加额〔银〕；支付原保险合同赔付款项的现金〔保〕；拆出资金净增加额〔证〕；支付利息、手续费及佣金的现金〔证〕；支付保单红利的现金〔保〕；支付给职工及为职工支付的现金；支付的各项税费；支付其他与经营活动有关的现金；经营活动现金流出小计；经营活动产生的现金流量净额。

投资活动：收回投资收到的现金、取得投资收益收到的现金、处置固定资产无形资产和其他长期资产收回的现金净额、处置子公司及其他营业单位收到的现金净额、收到其他与投资活动有关的现金、投资活动现金流入小计；购建固定资产无形资产和其他长期资产支付的现金、投资支付的现金、质押贷款净增加额〔银〕、取得子公司及其他营业单位支付的现金净额、支付其他与投资活动有关的现金、投资活动现金流出小计；投资活动产生的现金流量净额。

筹资活动：吸收投资收到的现金（其中：子公司吸收少数股东投资收到的现金）、取得借款收到的现金、收到其他与筹资活动有关的现金、筹资活动现金流入小计；偿还债务支付的现金、分配股利利润或偿付利息支付的现金（其中：子公司支付给少数股东的股利利润）、支付其他与筹资活动有关的现金、筹资活动现金流出小计；筹资活动产生的现金流量净额。

尾项：汇率变动对现金及现金等价物的影响、现金及现金等价物净增加额、加：期初现金及现金等价物余额、期末现金及现金等价物余额。

### 3.4 所有者权益变动表（时点数 + 期间变动）

结构：行 = 变动原因（上年年末余额、会计政策变更、前期差错更正、本年年初余额、本年增减变动金额、综合收益总额、所有者投入和减少资本、利润分配、所有者权益内部结转、专项储备提取和使用、本年年末余额），列 = 股本、其他权益工具（优先股、永续债）、资本公积、减：库存股、其他综合收益、专项储备、盈余公积、一般风险准备〔银〕、未分配利润、所有者权益合计。

摄取策略：整表按「列科目 × 期末余额」取时点值，外加四类关键变动行（综合收益总额、利润分配—对所有者的分配、所有者投入、内部结转）供勾稽与派生使用。

## 4. 字典外科目处理

36 号文明确金融企业可按重要性原则删减或增设报表项目，新准则也会引入新科目。规则：

1. 摄取遇到字典外科目：保留原文科目名入库，listed=false，不猜测映射、不丢弃。
2. 审校阶段审阅 listed=false 的科目，决定收编（字典 dict_version+1）或合并到语义等价的既有科目（在字典备注留映射记录）。
3. 摄取层和问答层引用科目时，字典内科目用标准名，字典外科目用原文带 listed 标记，两者不混写。

## 5. 勾稽校验（入库前跑，失败不写入）

| 编号 | 规则 | 容差 |
|---|---|---|
| R1 | 资产总计 = 负债合计 + 所有者权益合计 | 相对误差 ≤ 0.5‰（吸收四舍五入） |
| R2 | 期末现金及现金等价物余额 − 期初现金及现金等价物余额 = 现金及现金等价物净增加额 = 三大活动净额 + 汇率变动影响 | 同上 |
| R3 | 期末未分配利润 = 期初未分配利润 + 归母净利润 − 提取盈余公积 − 对所有者（或股东）的分配（取所有者权益变动表） | 同上 |
| R4 | 净利润 = 现金流量表补充资料起点净利润（年报披露补充资料时校验） | 同上 |

失败处理：整份报表数值先挂起（不入库），错误清单进审校报告，人工裁决后放行或退回；不自动改数。
