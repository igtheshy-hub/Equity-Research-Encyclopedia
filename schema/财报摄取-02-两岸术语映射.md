# 财报摄取·两岸术语映射表（草案 v0.1）

状态：讨论稿，未接入程序。
日期：2026-10-12

用途：SKILL.md（financial-statement-reading）以台湾 IFRS 术语撰写，本表把其中的术语映射到 A 股报表科目（大陆企业会计准则口径），供两个场景使用：
1. 摄取层：把 SKILL.md 的指标公式改写成大陆科目公式（见 03 号文档）
2. 问答层：分析框架引用台湾概念时，落到 A 股数据上取数

来源说明：搜索未找到现成的权威两岸对照表，本表由财会〔2019〕6号/16号/36号文的官方行项目与台湾 TIFRS 报表格式逐项对照自建。同名条目两侧一致，异名条目给出对应关系，口径不同的在注记中说明。

## 2. 口径陷阱（问答层引用台湾基准时必读）

陷阱一：营业利益 ≠ 营业利润。台湾营业利益是 IFRS 口径，营业毛利减营业费用，不含投资收益；大陆营业利润 = 营业收入 − 营业总成本 + 其他收益 + 投资收益 + 公允价值变动收益 + 信用减值损失 + 资产减值损失 + 资产处置收益，把投资类与减值类损益全部算进来了。SKILL.md 讲的营业利益率、营业费用率若直接拿 A 股营业利润计算，口径偏宽。可比口径需自行构造「核心营业利润 = 营业收入 − 营业成本 − 税金及附加 − 销售费用 − 管理费用 − 研发费用 − 财务费用」，此构造口径已列入 03 号文档的指标字典（标注为派生、自定义口径）。

陷阱二：现金及约当现金 ≠ 货币资金（严格意义）。A 股资产负债表的货币资金含使用受限的部分（保证金、冻结存款等），现金流量表的现金及现金等价物不含受限资金。SKILL.md 的现金分析落 A 股数据时，流动性看货币资金，现金流勾稽看现金流量表期末余额，两者差异大时要查附注的受限资金披露。

陷阱三：负债比参考线的产业基准不同源。SKILL.md 的「高科技 ≤ 40%、一般制造 ≤ 60%」是台湾上市公司经验值，A 股各产业杠杆结构不同（建筑业、地产显著更高），问答层引用时按国内行业分布重新校准，不直接照搬阈值。

## 3. 基准线归属

SKILL.md 中的判断阈值（DSO < 90 天、DIO 30—60 天且 < 20 天可疑、流动比率 > 120%、负债比参考线等）属于作者观点而非公司数据，全部归问答层（第二部分）的参考知识，摄取层不存阈值，只存供其计算的指标原值。问答层输出分析时引用阈值必须注明出处（张明辉，映射自该 skill）。
