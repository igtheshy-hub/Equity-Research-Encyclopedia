# 财报摄取 skill 本体（v1.0，已接入程序）

状态：已实现。实现产物：src/filing.py（四段式流程，ingest_one 对 filing 类自动分流）、src/fin_calc.py（勾稽与指标计算器）、schema/filing_items.json（机器可读科目别名表）、data/fin/（结构化存储）。本文件是摄取 skill 的流程指令，引用三份参考文档：
- 01 科目字典（科目清单、数据字段、勾稽校验）
- 02 两岸术语映射（口径陷阱）
- 03 多口径指标字典（派生指标公式与报告期处理）

落法说明：本流程与最终实现方式无关。化成管线提示词加校验代码，或写成 Claude Code skill 手动触发，流程与输出契约不变。

## 1. 定位与职责边界

本 skill 处理已归入 raw/filings/ 的财报（filing 类），产出且仅产出三类客观内容：

1. 科目原值（四表数据行）
2. 派生指标（按指标字典多口径计算）
3. 管理层引述（MD&A、经营讨论、重要事项中的原话，标注语境）

以下内容禁止产出：趋势评论、好坏判断、阈值评价、预测、跨期对比的定性描述。同比、单季、TTM 数值本身属于派生指标可以计算，但「增长强劲」「优于同业」之类的表述一律不写。判断类内容归问答 skill（见 财报问答-skill.md）。

## 2. 工作流

### 第一步：识别

从封面、页眉、审计报告页提取：

1. 公司规范名（与 wiki 现有公司页名对齐，对不上按现有归并规则处理）
2. 报告期类型（Q1/H1/Q3/FY）与截止日
3. 报表范围：合并与母公司两套都要抽取，scope 字段区分；母公司科目只进 data/fin 结构化存储，不进 wiki 页面（避免页面膨胀，v1.0 修正）
4. 审计意见类型（标准无保留 / 带强调事项段 / 保留 / 无法表示意见）——客观事实，记入 source 页材料信息
5. 报表格式版本：2018 年及以前的旧格式科目（如「应收票据及应收账款」合并列示）按 02 号文档规则归一，归一不了的保留原科目名并备注「旧格式合并披露」

### 第二步：定位四表

找到合并资产负债表、合并利润表、合并现金流量表、合并所有者权益变动表（及母公司四表）所在页，记录页码区间，后续锚点取自这些页。现金流量表补充资料（折旧摊销明细）若披露，一并定位。

### 第三步：逐表抄录

1. 按 01 号字典顺序逐科目抄录，只抄数不改数，数值带锚点
2. 字典外科目：保留原文科目名，listed=false，不猜测映射
3. 缺失科目：跳过并记入缺失清单，不留空、不估数
4. 单位按披露记录，抄录后统一换算为元

### 第四步：勾稽校验

跑 01 号字典 R1—R4 四条规则，容差 0.5‰。任一失败：整份报表数值挂起，不入库，错误清单交审校；不自动修数。部分勾稽依赖的数据缺失（如季报无补充资料）时，对应规则跳过并记录，不影响其余校验。

实现注记（v1.0）：R4 因补充资料行名歧义暂未实现，实际校验为 R1、R2（含期末−期初子校验两条）、R3（容差放宽 5 倍），见 src/fin_calc.py check_reconciliations。

### 第五步：派生计算

1. 按 03 号字典计算派生指标，多口径全算，每条带口径标签
2. 分母或科目缺失的指标跳过，记入缺失清单；按字典规则允许近似的（如 ROIC 利息费用以财务费用近似）打 degraded 标签
3. 报表披露值（加权平均 ROE、银行 NIM 等）直接摄取，派生口径并存不覆盖

### 第六步：管理层引述提取

从 MD&A / 董事会报告 / 重要事项中提取：经营情况说明、会计政策变更、业绩指引、风险因素的原话。逐条带锚点，标注语境（指引 / 政策变更 / 风险提示）。营销性、样板性、免责性文字丢弃。引述是「公司说了什么」的事实，不是本 skill 的观点。

### 第七步：落库

公司页「经营与财务」节按固定行格式追加（见第 3 节），旧数据行不删改，同公司新报告期只增行。source 页按现有规则生成，材料信息含报告期、审计意见、条目数。manifest 记录沿用现有字段。

## 3. 行格式契约（wiki 页内的结构化行）

 wiki 正文一行一条，固定语法，供程序与问答层解析：

- 科目行：【数据】报告期 scope 科目 = 数值元 [[锚点]]
  例：【数据】2026H1 合并 营业收入 = 81,580,000,000 元 [[某某公司2026半年报.pdf#p7]]
- 指标行：【指标】报告期 指标名(口径标签) = 数值 [[锚点]][[锚点]]
  例：【指标】2026H1 ROE(归母平均) = 0.172 [[半年报.pdf#p7]][[半年报.pdf#p60]]
  锚点取该指标取数科目的锚点集合。披露值口径标签写「披露」。
- 引述行：【管理层】「原话」——语境 [[锚点]]
- 缺失记录：不写入页面，只在 source 页材料信息下列缺失清单（科目与指标分列）

行格式合法性由程序校验（正则可解析、数值可读、锚点真实），违规行丢弃并计数，沿用现有锚点校验机制。

## 4. 幂等与重复

同一文件 SHA256 一致跳过（现有机制）。同一报告期不同来源文件（如正式年报与更正版）：按文件分别摄取，数据行并存，source 页各自记录；审校阶段人工裁决冲突。

## 5. 程序实现要求（v1.0 已全部实现）

1. 行格式正则校验器 → src/validate.py（validate_all 内 _line_format_problems）
